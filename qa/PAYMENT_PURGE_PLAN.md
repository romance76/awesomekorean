## 같이 정리할 연결 기록
- 인보이스 + 발송 기록(invoice_deliveries)
- 전단 광고(flyer_ads) + 예약 시간(flyer_slots) + 광고 잔액 기록(ad_credit_logs, users.ad_credit_cents 되돌림)
- 배너·텍스트 광고(banner_ads)
- 공동구매(group_buys) + 참가자 + 쿠폰 + 쿠폰 사용 기록
- 상위노출: 글(장터·구인구직)은 지우지 않고 상위노출 표시만 해제
- Stripe 쪽 결제와 업로드된 이미지 파일은 건드리지 않는다

## 앞으로도 쓸 수 있게 — "결제 정리" 관리자 기능 (제안)
1. 최고관리자 + 재확인(reauth) 전용. 오더/결제 화면의 "시험 결제 정리" 창.
2. 지울 결제를 체크 → **미리보기**(무엇이 같이 사라지는지, 인보이스 번호, 경고) → "삭제" 직접 입력 → 삭제.
3. **막는 경우**: 카드 보류(authorized)가 걸린 결제, 승인 대기·게시 중 광고가 연결된 결제.
4. **백업**: 지우기 전에 연결 기록 전체를 JSON 으로 서버(`storage/app/…/purge_backups/`)에 저장, 한 트랜잭션으로 삭제(실패하면 전부 되돌림), 로그 남김.
5. 옵션 "연결된 광고·공동구매도 같이 지우기"(기본 켬) / 끄면 결제 번호만 떼어 냄.

## 결정이 필요한 것
- 인보이스 번호 AK-2026-000001~4 는 빈 번호가 된다 (새 실결제는 000005 부터가 아니라 마지막 번호 다음으로 이어질지 확인 필요).
- 공동구매 #71(시험 글)을 통째로 지워도 되는지.
- 시험 결제를 지우는 대신 "시험"으로 표시해 매출 통계에서만 빼는 방법(되돌릴 수 있음)을 쓸지.
