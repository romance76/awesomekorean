# SNS 자동 게시 계획서 (인스타그램 · 스레드)

작성: 2026-10-12 UTC 19:00 (애틀랜타 오후 3:00) · 상태: **Kay "제안대로" 확정(2026-10-12 UTC 19:50) → 1차 구현 배포**
이미 한 것: 관리자 › 사이트 설정 › **SNS 계정** 탭 — 계정 정보 저장(아래 4번).

---

## 1. 목표
어썸코리안에 올라오는 MONEY 카페 글(운영팀 글)·머니 가이드(필요하면 내돈내산 리뷰)를 사이트 공식 **인스타그램**과 **스레드** 계정에 자동으로 올려서, SNS 에서 사이트로 사람을 데려온다.

## 2. 가능한가 — 네 (Meta 공식 API)
| | 인스타그램 | 스레드 |
|---|---|---|
| 공식 API | Instagram Graph API (Content Publishing) | Threads API |
| 계정 조건 | **비즈니스 또는 크리에이터 계정** + **페이스북 페이지 연결** 필수 | 스레드 계정(인스타 계정으로 만든 것) |
| 글 형식 | **사진 필수**(1장 또는 여러 장 캐러셀, JPEG), 캡션 2,200자 | 글 500자 + 사진/링크 선택 |
| 링크 | 캡션 속 링크는 **눌리지 않음** → "프로필 링크에서 보기" | 링크가 눌림(미리보기 카드) |
| 하루 한도 | API 게시 하루 수십 건(정확한 숫자는 Meta 문서 확인) | 하루 수백 건 |
| 권한 | instagram_content_publish 등 | threads_basic, threads_content_publish |
| 심사 | 우리 계정에만 올리면 보통 **앱 심사 없이** 가능(앱 관리자·테스터 역할 계정) | 동일 |
| 토큰 | 장기 토큰 **60일** — 만료 전 자동 연장 필요 | 장기 토큰 60일, 연장 가능 |

## 3. 동작 방식 (제안)
1. **게시 대기열** `social_posts` 표: 원본(money_post / money_guide / shopping), 플랫폼, 캡션, 이미지 주소, 상태(대기·승인·게시됨·실패·건너뜀), 예약 시각, 게시 ID·주소, 오류 메시지, 시도 횟수.
2. **대기열에 넣기**: 새 MONEY 운영팀 글이 동기화될 때 자동으로 "대기" 등록(기존 250여 편은 관리자가 골라서 넣기 — 한꺼번에 올리지 않음).
3. **승인**(처음 몇 주 제안): 관리자 › SNS 게시 화면에서 캡션·이미지 미리보기 → 고치기 → 승인. 나중에 "자동 승인"으로 바꿀 수 있음.
4. **예약 게시**: 스케줄러가 정해 둔 시간(예: 애틀랜타 오전 8시·낮 12시·저녁 7시)에 승인된 것을 하루 정해진 개수만 게시. 실패하면 3번까지 다시 시도, 그래도 안 되면 "실패"로 표시하고 관리자 알림.
5. **인스타 이미지 만들기**: 글마다 **카드뉴스 이미지**(1080×1350, 카페 색 배경 + 카페 이름 + 제목 + 핵심 3줄 + awesomekorean.com 로고)를 서버에서 자동 생성해 `storage/app/public/social/` 에 저장(공개 https 주소 필요 — 인스타가 그 주소에서 가져감).
   - 선택안: 카드뉴스 1장 + 글 속 공식 화면 캡처 2~4장을 **캐러셀**로.
6. **캡션 만들기**: 제목 + 요약 3줄 + "자세히: 프로필 링크"(인스타) / 글 주소(스레드) + 해시태그 5개 내외(#미국생활 #애틀랜타한인 #미국세금 등, 카페별 기본값을 관리자에서 수정).
7. **비상 스위치** "SNS 자동 게시 멈추기"(기존 `EmergencySwitches` 에 추가) + 계정별 "자동 게시" 체크.
8. **토큰 자동 연장**: 매주 한 번 만료 15일 안이면 연장 API 호출, 실패하면 관리자에게 알림(만료되면 게시가 멈춤).
9. **기록**: 게시·실패·승인 모두 감사 로그. 게시된 SNS 주소를 글 관리자 화면에서 볼 수 있게.

## 4. 계정 정보 저장 (완료 — 이번 배포)
- 관리자 › 사이트 설정 › **SNS 계정** 탭(최고관리자 전용, 저장 시 비밀번호 재확인).
- 저장 칸: 계정 아이디·프로필 주소·계정 이메일(참고)·인스타 비즈니스 계정 ID / 스레드 사용자 ID·페이스북 페이지 ID·Meta 앱 ID·**앱 시크릿(암호화)**·**액세스 토큰(암호화)**·토큰 만료일·메모·사용/자동 게시 체크.
- 비밀값은 `APP_KEY` 로 암호화해 `social_accounts` 표에 저장, 화면에는 끝 4자리만. 감사 로그에는 "어떤 칸을 바꿨는지"만 남김(값은 안 남김).
- **계정 비밀번호는 저장하지 않음** — 자동 게시는 토큰으로만 하고, 비밀번호를 DB 에 두면 사이트가 털릴 때 SNS 계정까지 넘어감. 비밀번호는 Kay 의 비밀번호 관리 앱에 보관 권장.
- 인스타 프로필 주소를 저장하면 사이트 아래쪽(푸터) 인스타 링크도 같은 주소로 바뀜.

## 5. Kay 가 직접 할 일 (로그인·권한 허용이라 대신할 수 없음)
1. 인스타그램 앱 › 설정 › 계정 유형 → **비즈니스(또는 크리에이터)** 로 전환.
2. **페이스북 페이지**(어썸코리안) 만들기 또는 기존 페이지에 인스타 연결(Meta Business Suite › 설정 › 연결된 계정).
3. developers.facebook.com → 앱 만들기(유형: Business) → 제품 추가: **Instagram**(Instagram API with Facebook Login) · **Threads API**.
4. 앱 역할에 Kay 계정을 관리자로, 스레드는 테스터로 초대 수락.
5. Graph API 탐색기 등으로 **장기 액세스 토큰** 발급 → 관리자 › SNS 계정에 붙여넣기(채팅에 붙여넣지 말 것). 계정 ID 도 같이.
   → 단계별 화면 안내서는 Kay 가 시작할 때 따로 만들어 드림.

## 6. Kay 결정 필요
1. **하루 개수**: 제안 인스타 2개 · 스레드 3개 (기존 글이 250편 넘음 → 이 속도면 약 3~4개월치).
2. **승인 방식**: 처음엔 관리자 승인 후 게시(제안) vs 처음부터 자동.
3. **범위**: MONEY 운영팀 글만(제안) / + 머니 가이드 / + 내돈내산 리뷰(회원 글은 작성자 동의 필요 → 제외 권장).
4. **인스타 형식**: 카드뉴스 1장(제안, 단순) vs 카드뉴스 + 공식 화면 캐러셀.
5. **게시 시간대**: 제안 애틀랜타 오전 8시·낮 12시·저녁 7시.
6. 해시태그 기본값·말투(존댓말 정보형 제안).

## 7. 주의할 점
- 공식 사이트 캡처(정부 사이트)는 SNS 에 올려도 대체로 문제없지만, **기업 앱 스토어 화면**은 캐러셀에서 빼는 것이 안전.
- 금융·세금 정보는 "일반 정보, 조언 아님" 문구를 캡션 끝에 짧게.
- 같은 글을 두 번 올리지 않게(원본+플랫폼 기준 중복 방지).
- 인스타 API 는 **사진을 공개 주소에서 가져가므로** 사이트가 느리거나 막히면 실패 → 자동 재시도.
- 회원이 쓴 글은 자동으로 올리지 않음(저작권·동의).

## 8. 만드는 순서 (확인 후, 작게 나눠 배포)
1. `social_posts` 표 + 관리자 "SNS 게시" 화면(대기열·미리보기·승인·실패 다시 시도) — 실제 게시 없이.
2. 카드뉴스 이미지 생성(서버 PHP GD, 한글 폰트 파일 포함) + 캡션 생성 + 미리보기.
3. 스레드 게시(텍스트+링크+사진) — Kay 토큰으로 1편 시험.
4. 인스타 게시(사진 1장 → 캐러셀) — 1편 시험.
5. 스케줄러·하루 한도·재시도·토큰 자동 연장·비상 스위치·알림.
6. 새 MONEY 글 자동 대기열 등록.
각 단계 끝에 `scripts/ship.sh` 배포 + 화면 확인 + 서버 롤백 시험.
