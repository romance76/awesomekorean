# 배포 후 확인 체크리스트 · 비상 스위치 목록

## 1) 배포 직후 — 1분 (자동)
```bash
bash qa/scripts/post_deploy_smoke.sh            # 기본: https://awesomekorean.com
```
홈·커뮤니티·장터·구인·정보 화면, 빌드 파일, 사이트맵, 공개 설정 API, 로그인(틀린 비밀번호 → 401), 2단계 인증·CSP 수신 주소,
보안 헤더, 홈 응답 속도(3초 미만)를 읽기 전용으로 확인합니다. 마지막 줄이 `ALL OK` 면 사이트가 살아 있는 것입니다.
`FAILED n` 이면 어떤 줄이 실패했는지 위에 `FAIL` 로 나옵니다.

## 2) 사람이 눈으로 — 3분 (관리자·회원 화면 왕복)
폰으로 한 번씩 열어 보세요. 이상하면 바로 직전 배포를 의심합니다.
- [ ] 홈이 열리고 카드·검색창이 보인다 (콘솔 오류 없음)
- [ ] 로그인 → 로그아웃 → 다시 로그인 (2단계 인증을 켠 계정이면 코드 칸이 나온다)
- [ ] 장터·구인·커뮤니티 목록이 뜨고 글 하나를 열어 본다
- [ ] 오픈 채팅방 입장 (메시지 목록이 뜬다)
- [ ] 정보(/info) 글 하나가 열린다
- [ ] 관리자: 대시보드 → 신고·문의 → 경품 추첨 관리 → 할 일 목록이 열린다
- [ ] 이번 배포에서 바꾼 화면을 직접 눌러 본다 (바뀐 곳만)

## 3) 문제가 생기면 — 되돌리는 법
| 상황 | 가장 빠른 방법 |
|---|---|
| 새 기능 때문에 화면이 이상함 | 아래 4) 의 스위치로 해당 기능만 끄기 → 원인 확인 후 수정 배포 |
| 배포 자체가 잘못됨 | GitHub 에서 문제의 커밋을 `Revert` 해서 main 에 올리면 자동으로 이전 상태로 배포됨 |
| 점검이 필요함 | 관리자 > 시스템 설정 > **점검 모드** 켜기 (관리자·운영자만 로그인 가능, 일반 회원은 점검 안내) |
| 2단계 인증으로 관리자가 잠김 | 다른 최고관리자가 해제하거나 서버에서 `php artisan user:2fa-reset 이메일` |

## 4) 끄는 스위치 목록 (킬 스위치)
**비상 스위치** — 관리자 화면(최고관리자)에서 한 번에 "일시 중지". 값은 `site_settings` 의 `emergency_<이름>_paused` ('1' 이면 멈춤). 읽다가 오류가 나면 "정상"으로 보아 스위치 때문에 사이트가 멈추지 않는다.
| 스위치 | 멈추는 것 |
|---|---|
| `signup_bonus` 가입 보너스 지급 | 가입 포인트·Entry, "매 N번째 가입" 경품 (가입 자체는 그대로) |
| `sweepstakes_schedules` 경품 반복 일정 | 반복 일정으로 새 경품 만들기, 자동 추첨 |
| `auto_collect` 자동 수집 | 음악·뉴스·숏츠 자동 수집 (관리자가 직접 누르는 수집은 가능) |
| `social_autopost` SNS 자동 게시 | 인스타그램·스레드 예약 글 올리기 (스레드 인증 문제가 있을 때 잠시 끄기 좋음) |

**사이트 설정 스위치** (관리자 > 시스템 설정, `SiteFlags`): 점검 모드, 가입 허용, 이메일 인증 필수, 최소 비밀번호 길이. 저장 즉시 반영된다.

**코드 스위치**: 큰 글씨 보기 `easy_view_enabled`(관리자 설정), 음성 통화 `VOICE_CALL_ENABLED`(`resources/js/config/features.js`, 지금 꺼짐).

**이번에 새로 만든 기능과 끄는 법**
| 기능 | 끄는 법 | 켜 두어도 안전한 이유 |
|---|---|---|
| 관리자 2단계 인증 | 계정별: 설정 화면에서 끄기 / 비상: `user:2fa-reset` | 스스로 켠 계정에만 적용. 안 켠 계정의 로그인은 달라지지 않음 |
| DB 자동 백업 | `routes/console.php` 의 `db:backup` 한 줄 삭제 | 읽기만 함, 디스크 1GB 미만이면 건너뜀, 7일 지난 것 자동 삭제 |
| CSP 보고 모드 | `SecurityHeaders` 의 `Content-Security-Policy-Report-Only` 줄 삭제 | 보고만 하고 아무것도 막지 않음 |

## 5) 스위치가 아직 없는 큰 기능 (필요할 때 추가)
새 큰 기능을 만들 때는 끄는 스위치를 같이 만듭니다(`EmergencySwitches::SWITCHES` 에 항목 추가 + 해당 코드 앞에 `EmergencySwitches::on('이름')` 검사).
지금 스위치 없이 항상 켜져 있는 것: 오픈 채팅방, 쪽지, 중고장터·부동산 자동 수집(`market:scrape`, `realestate:scrape` — 스케줄 줄 삭제로 끔), 푸시 알림.
