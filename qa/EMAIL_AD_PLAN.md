# 이메일 수신 동의 + 광고 메일 발송 계획 (2026-10-22 초안)

목표: ① 회원이 "광고·소식 메일 받기"에 **직접 동의**하게 하고, ② 사이트에 광고를 낸 광고주가 원하면 **광고 지역 + 인접 주**의 동의 회원에게 광고 내용을 메일로 보내 준다.
예) 뉴욕(NY) 광고주가 "전체 광고"를 샀다 → NY와 인접 주(NJ·CT·PA·MA·VT)에 사는 **수신 동의 회원**에게만 발송.

## 0. 원칙 (어기면 발송 서비스 정지·벌금 위험)
- **동의한 사람에게만** 보낸다. 이메일을 긁어 오거나 사지 않는다. 동의하지 않은 회원에게 광고 메일 금지(거래·인증 메일은 별개).
- 모든 광고 메일에 ① "광고" 표시 ② 보내는 사람 실제 이름·**우편 주소** ③ **수신 거부 링크**(한 번 클릭) 를 넣는다. 수신 거부는 즉시 반영(법은 10영업일 이내).
- 광고주에게 회원 이메일 주소를 **절대 넘기지 않는다**. 발송은 사이트가 대신한다.
- 법률 해석은 변호사 확인 필요(미국 CAN-SPAM, 주법, Gmail·Yahoo 대량 발송 기준). 이 문서는 운영 설계안.

## 1. 수신 동의 수집
| 접점 | 방식 |
|---|---|
| 회원가입 | 체크박스 "이벤트·지역 광고·소식 메일 받기(선택)". **기본값 체크 안 됨.** |
| 기존 회원 | 로그인 후 1회 안내 배너 + 마이페이지 > 알림 설정에 스위치 |
| 뉴스레터 구독 폼 | 정보 글 하단·홈에 이메일 입력 → **확인 메일의 링크를 눌러야 구독 완료(더블 옵트인)** |
| 경품 응모 | 응모 화면에 별도 체크(응모 조건으로 강요 금지) |
- 저장할 것: 동의 여부, 동의 시각, 동의 경로(가입/배너/구독폼), IP, 동의 문구 버전, 수신 거부 시각.
- 회원이 아닌 구독자도 받을 수 있게 구독자 테이블을 따로 둔다(주 코드는 입력받거나 우편번호로).
- 이메일 인증을 마친 회원에게만 발송(이미 `email_verified_at` 있음).

## 2. 지역 기준 (이미 있는 것 활용)
- 회원 주(state)는 `users.state` 사용. 비어 있으면 도시·우편번호로 보정, 그래도 모르면 **광고 메일 대상에서 제외**(전국 광고만).
- 인접 주 계산은 기존 `StateNeighbors` 사용(NY → NY, NJ, CT, PA, MA, VT).
- 광고 범위(`scope`): `national`(전국) / `state`(주 + 인접 주). 전면광고(`flyer_ads`)의 `scope`·`region_key` 개념과 같게 맞춘다.

## 3. 광고주용 메일 상품
- **상품 이름 예:** "지역 메일 광고" (전면광고·배너 구매와 별도 옵션).
- **발송 방식:** 광고 1건을 단독 메일로 보내지 않고, **주 1~2회 "이번 주 한인 소식·광고" 묶음 메일**에 최대 3건까지 실어 보낸다 → 스팸 신고 감소, 수신 피로 감소.
- **광고주가 입력:** 제목(40자), 한 줄 소개(80자), 이미지 1장, 본문 짧게, 링크, 전화, 유효기간. 광고주가 정할 수 있는 범위: 내 주만 / 내 주 + 인접 주 / 전국.
- **가격:** 받는 사람 수(예상 도달 인원) × 단가로 계산하거나 구간제(예: 500명 이하 / 2,000명 이하 / 그 이상). 결제는 기존 광고 결제(포인트·카드) 흐름 재사용. 예상 인원은 결제 전에 보여 준다(개인정보 없이 숫자만).
- **심사:** 관리자 승인 후 발송(기존 광고 승인 화면 재사용). 금지 업종(불법·의료 과장·투자 권유 등)은 기존 광고 규칙과 동일 적용.
- **결과 보고서:** 발송 수, 열람 수, 클릭 수(추적 링크). **누가 클릭했는지는 광고주에게 주지 않는다.**

## 4. 발송 규칙 (회원 보호 + 도메인 보호)
- 회원 1명당 광고 메일은 **주 1회 이하**(월 4회 상한). 같은 광고주 광고는 연속 2주 이상 금지.
- 발송 시간: 수신자 현지 시간 오전 9~11시(동·서부 시차 반영).
- 수신 거부·반송·스팸 신고가 일정 기준을 넘으면 **자동 중단**(스팸 신고율 0.1% 미만 목표, 0.3% 넘으면 위험).
- 3회 연속 안 열어 본 회원은 "계속 받으시겠어요?" 확인 메일 → 답 없으면 발송 대상에서 제외.
- 새 발송 도메인/주소는 **적은 수로 시작해 서서히 늘린다(워밍업)**: 첫 주 200통 → 2배씩.

## 5. 기술 준비물 (현재 코드 기준)
- 메일 발송은 이미 Resend 사용 중(인증·초대 메일). **광고 메일은 인증 메일과 다른 발송 주소**(예: news@mail.awesomekorean.com)로 분리해, 광고에 문제가 생겨도 로그인·인증 메일이 영향받지 않게 한다.
- 도메인 설정: SPF·DKIM·DMARC 확인, 헤더에 `List-Unsubscribe`(원클릭) 추가 — Gmail·Yahoo 대량 발송 필수 조건.
- 새 DB: 수신 동의 기록, 구독자(비회원), 메일 광고 신청, 발송 대상·결과 기록, 수신 거부 목록.
- 새 화면: 가입 폼 체크박스, 마이페이지 알림 설정, 구독 폼, 수신 거부 페이지, 광고주 "메일 광고 신청" 화면(미리보기·예상 인원), 관리자 승인·발송 현황.
- 발송은 큐로 나눠 보낸다(서버 메모리 작음 → 한 번에 수십~수백 통씩).

## 6. 단계별 일정
1. **1단계 — 동의 수집(먼저, 1주):** 가입 체크박스, 마이페이지 스위치, 안내 배너, 구독 폼(더블 옵트인), 수신 거부 페이지. 동의 기록 저장. 이 단계는 발송 없이 동의자부터 쌓는다.
2. **2단계 — 자체 뉴스레터 시험(1~2주):** 사이트 소식·생활정보 요약을 주 1회, 동의자 일부에게 발송. 열람·수신 거부율 점검, 발송 주소·도메인 점검.
3. **3단계 — 광고주 메일 광고(2주):** 신청·승인·예상 인원·묶음 메일·결과 보고. 처음엔 **무료 시험 광고주 2~3곳**(뉴욕·애틀랜타·LA 등)과 시작.
4. **4단계 — 유료 전환:** 가격표 확정, 결제 연결, 광고주 안내 페이지. 동의자가 최소 몇 명 이상 쌓인 지역부터 판매(예: 해당 지역 동의자 300명 미만이면 판매 보류).

## 7. 지금 정해야 할 것
1. 발송 주소·사이트 우편 주소(법적으로 메일에 표시). 사업장 주소 또는 사서함.
2. 회원이 아닌 사람(구독자)에게도 광고 메일을 보낼지(권장: 처음엔 회원+더블 옵트인 구독자만).
3. 광고 메일 가격 방식(인원 비례 / 구간제 / 정액).
4. 무료 시험 광고주 후보.
5. 광고주에게 "받은 사람 수·열람·클릭"까지 공개할지.

## 8. 위험과 대비
- 동의율이 낮아 도달 인원이 적을 수 있음 → 가입·응모·정보 글 하단에 동의 접점을 늘리고, 동의 혜택(응모권 1개 등, 단 동의를 강요하지 않는 선에서) 검토.
- 광고주가 "내 손님 이메일을 달라"고 요구 → 거절(개인정보·동의 범위 밖), 대신 결과 보고서 제공.
- 스팸 신고 증가 → 자동 중단 규칙과 주 1회 상한이 방어선.
- 인접 주 정의가 광고주 기대와 다를 수 있음 → 신청 화면에서 포함되는 주 목록을 미리 보여 주고 직접 빼거나 더할 수 있게 함.
