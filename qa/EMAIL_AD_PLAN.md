# 이메일 수신 동의 + 광고 메일 발송 계획 (2026-10-22 초안 · 광고주 혜택 방식 수정판)

목표: ① 회원이 "광고·소식 메일 받기"에 **직접 동의**하게 하고, ② 사이트에 광고를 낸 광고주가 원하면 **광고 지역 + 인접 주**의 동의 회원에게 광고 내용을 메일로 보내 준다.
예) 뉴욕(NY) 광고주가 "전체 광고"를 샀다 → NY와 인접 주(NJ·CT·PA·MA·VT)에 사는 **수신 동의 회원**에게만 발송.

## 0. 원칙 (어기면 발송 서비스 정지·벌금 위험)
- **동의한 사람에게만** 보낸다. 이메일을 긁어 오거나 사지 않는다. 동의하지 않은 회원에게 광고 메일 금지(거래·인증 메일은 별개).
- 모든 광고 메일에 ① "광고" 표시 ② 보내는 사람 실제 이름·**우편 주소** ③ **수신 거부 링크**(한 번 클릭) 를 넣는다. 수신 거부는 즉시 반영(법은 10영업일 이내).
- 광고주에게 회원 이메일 주소를 **절대 넘기지 않는다**. 발송은 사이트가 대신한다.
- 법률 해석은 변호사 확인 필요(미국 CAN-SPAM, 주법, Gmail·Yahoo 대량 발송 기준). 이 문서는 운영 설계안.

## 1. 수신 동의 수집
| 접점 | 방식 |
|---|---|
| 회원가입 | 체크박스 "이벤트·지역 광고·소식 메일 받기(선택)". **기본값 체크 안 됨.** |
| 기존 회원 | 로그인 후 1회 안내 배너 + 마이페이지 > 알림 설정에 스위치 |
| ~~뉴스레터 구독 폼~~ | **쓰지 않음**(비회원에게는 보내지 않기로 결정) |
| 경품 응모 | 응모 화면에 별도 체크(응모 조건으로 강요 금지) |
- 저장할 것: 동의 여부, 동의 시각, 동의 경로(가입/배너/구독폼), IP, 동의 문구 버전, 수신 거부 시각.
- 수신 대상은 **회원만**(비회원 구독자 테이블 불필요).
- 이메일 인증을 마친 회원에게만 발송(이미 `email_verified_at` 있음).

## 2. 지역 기준 (이미 있는 것 활용)
- 회원 주(state)는 `users.state` 사용. 비어 있으면 도시·우편번호로 보정, 그래도 모르면 **광고 메일 대상에서 제외**(전국 광고만).
- 인접 주 계산은 기존 `StateNeighbors` 사용(NY → NY, NJ, CT, PA, MA, VT).
- 광고 범위(`scope`): `national`(전국) / `state`(주 + 인접 주). 전면광고(`flyer_ads`)의 `scope`·`region_key` 개념과 같게 맞춘다.

## 3. 광고주 혜택 — 두 갈래 (둘 다 광고주 추가 비용 없음)

### 3-A. 전면광고 광고주: "회원 메일 자동 발송" 특권 (무료)
- 전면광고(`flyer_ads`)를 신청해 **승인된** 광고주의 광고를, 어썸코리안이 **자동으로** 수신 동의 회원에게 메일로 보낸다. 광고주는 따로 신청·결제하지 않는다.
- **받는 사람:** 광고 범위(`scope`/`region_key`)에 맞춘다. 전국(ALL)이면 동의 회원 전체, 주 단위면 그 주 + 인접 주(`StateNeighbors`)의 동의 회원.
- **발송 시점(확정):** 광고 기간을 시작일부터 **7일 단위 주**로 나누어, **각 주의 마지막 날**에 1회 보낸다. 예) 3주 광고 → 3번(7일째·14일째·21일째). 마지막 주가 7일보다 짧으면 광고 종료일에 보낸다. 발송 시각은 받는 사람 현지 오전.
- **메일 모양:** 전면광고에 올린 이미지·제목·소개·전화·링크를 그대로 사용(광고주가 따로 쓸 것 없음). "광고" 표시 + 수신 거부 링크 포함.
- **회원 피로 방지:** 회원 1명이 받는 "전면광고 단독 메일"은 **주 1통 이하**(광고가 여러 개 겹친 날은 한 통에 묶음). 한 주에 여러 광고가 몰리면 한 통에 묶어서 보낸다(최대 3건), 넘치는 것은 다음 주 메일로 미룬다. 광고주에게는 승인 화면에서 "회원 메일 발송 예정일"(각 주 마지막 날)을 알려 준다.
- **광고주에게 보여 주는 것:** 발송 수·열람 수·클릭 수만. 받는 사람 이름·이메일은 절대 공개하지 않는다.

### 3-B. 사이트 양옆(사이드) 광고 광고주: 정기 메일 맨 아래 "지역 광고 띠" (무료)
- 양옆 배너 광고는 **광고만 따로 메일을 보내지 않는다.** 어썸코리안이 회원에게 정기적으로 보내는 메일(이번 주 소식·생활정보 요약 등) **맨 아래**에 "우리 동네 광고" 띠(배너 줄)로 함께 실린다. → 광고 때문에 매일 메일이 가는 일이 없다.
- **광고 고르기:** 받는 회원의 주 + 인접 주에 해당하는 사이드 광고 중에서 **발송할 때마다 무작위로 3~5개** 뽑는다(광고 노출 기회가 고르게 돌아가도록, 최근에 많이 실린 광고는 가중치를 낮춤).
- **마키(흐르는 배너)에 관한 중요한 제약:** 이메일에서는 `<marquee>`·CSS 애니메이션·자바스크립트가 Gmail·Outlook·Apple 메일 등 대부분에서 **작동하지 않거나 삭제**된다. 그래서 두 가지로 구현한다.
  1. **기본(모든 메일 앱에서 확실):** 정지된 배너 3~5개를 가로로 나란히(좁은 화면에서는 세로로) 보여 준다.
  2. **마키 느낌(선택):** 배너들을 이어 붙여 **움직이는 GIF** 하나로 만들어 메일에 넣는다. 지원 안 되는 앱(일부 Outlook)은 첫 장면만 정지 이미지로 나온다. GIF는 용량이 커서(1MB 이하 유지) 메일 로딩이 느려질 수 있으니 시험 후 결정.
  - 사이트 화면의 배너는 그대로 마키로 흐르고, 메일에서만 위 방식을 쓴다.
- **클릭 추적:** 배너마다 추적 링크로 열람·클릭 수를 센다. 광고주에게는 "이번 달 메일 노출 N회·클릭 N회"를 보고서로 보여 준다.
- **광고주 입장:** 별도 신청 없이, 사이드 광고가 승인되어 있고 광고 범위가 맞으면 자동으로 후보에 들어간다. 광고주가 원치 않으면 "메일 광고 제외" 스위치를 둔다.

### 3-C. (나중에) 유료 상품
- 전면광고·사이드 광고 혜택과 별개로, **메일 전용 단독 광고**(회원 수 비례 요금)는 동의자가 충분히 쌓인 뒤 4단계에서 검토한다.

## 4. 발송 규칙 (회원 보호 + 도메인 보호)
- 회원 1명이 받는 메일: **전면광고 단독 메일은 주 1통 이하**, 정기 소식 메일은 주 1~2회. 사이드 광고 띠는 정기 메일 맨 아래에만 들어가므로 광고 때문에 추가로 가는 메일은 없다. 같은 광고주의 광고가 연속해서 계속 실리지 않게 무작위·가중치로 돌린다.
- 발송 시간: 수신자 현지 시간 오전 9~11시(동·서부 시차 반영).
- 수신 거부·반송·스팸 신고가 일정 기준을 넘으면 **자동 중단**(스팸 신고율 0.1% 미만 목표, 0.3% 넘으면 위험).
- 3회 연속 안 열어 본 회원은 "계속 받으시겠어요?" 확인 메일 → 답 없으면 발송 대상에서 제외.
- 새 발송 도메인/주소는 **적은 수로 시작해 서서히 늘린다(워밍업)**: 첫 주 200통 → 2배씩.

## 5. 기술 준비물 (현재 코드 기준)
- 메일 발송은 이미 Resend 사용 중(인증·초대 메일). **광고 메일은 인증 메일과 다른 발송 주소**(예: news@mail.awesomekorean.com)로 분리해, 광고에 문제가 생겨도 로그인·인증 메일이 영향받지 않게 한다.
- 도메인 설정: SPF·DKIM·DMARC 확인, 헤더에 `List-Unsubscribe`(원클릭) 추가 — Gmail·Yahoo 대량 발송 필수 조건.
- 새 DB: 수신 동의 기록, 구독자(비회원), 메일 광고 신청, 발송 대상·결과 기록, 수신 거부 목록.
- 새 화면: 가입 폼 체크박스, 마이페이지 알림 설정, 구독 폼, 수신 거부 페이지, 광고주 "메일 광고 신청" 화면(미리보기·예상 인원), 관리자 승인·발송 현황.
- 발송은 큐로 나눠 보낸다(서버 메모리 작음 → 한 번에 수십~수백 통씩).

## 6. 단계별 일정
1. **1단계 — 동의 수집(먼저, 1주):** 가입 체크박스, 마이페이지 스위치, 안내 배너, 구독 폼(더블 옵트인), 수신 거부 페이지. 동의 기록 저장. 이 단계는 발송 없이 동의자부터 쌓는다.
2. **2단계 — 정기 소식 메일 + 맨 아래 광고 띠(1~2주):** 이번 주 소식·생활정보 요약 메일을 주 1회 동의자 일부에게 발송. 맨 아래에 사이드 광고 띠(정지 배너)를 무작위로 넣어 열람·클릭·수신 거부율과 메일 앱별 모양을 점검. 마키 느낌(GIF)은 여기서 시험.
3. **3단계 — 전면광고 자동 발송(1~2주):** 승인된 전면광고를 시작일에 지역별로 발송, 주 1통 상한·묶음 발송, 광고주 결과 보고서.
4. **4단계 — 확대·유료 검토:** 동의자 수가 충분한 지역부터 전면 적용. 메일 전용 단독 광고(유료)는 이때 가격을 정해 도입 여부 결정.

## 7. 확정된 결정 (2026-10-22)
| 항목 | 결정 |
|---|---|
| 보내는 주소 | `noreply@awesomekorean.com` (답장 불가 주소 — 문의는 사이트 안내 링크로) |
| 정기 소식 메일 | **매주 월요일** 발송, 맨 아래에 사이드 광고 띠(정지 배너) |
| 전면광고 자동 발송 | 신청 광고주에게 무료, **각 주의 마지막 날 1회**(3주 광고면 3번) |
| 마키 느낌 | **정지 배너**로 시작(움직이는 GIF는 쓰지 않음) |
| 비회원 구독자 | **보내지 않음** — 수신 동의한 회원에게만 |
| 광고주 보고서 | **공개하지 않음** (발송·열람·클릭 수는 관리자만 봄) |
| 우편 주소 | **미정** — 법적으로 광고 메일에 실제 우편 주소를 적어야 함(사업장 주소 또는 사서함). 정해지면 메일 맨 아래에 표시 |

### 결정에 따른 변경 사항
- 구독 폼(비회원)은 **만들지 않는다.** 1단계는 가입 체크박스·마이페이지 스위치·안내 배너·수신 거부 페이지·동의 기록만.
- 광고주 화면의 "발송·열람·클릭 보고서"는 만들지 않는다. 대신 관리자 화면에 전체 현황만.
- 월요일 정기 메일과 "각 주 마지막 날" 전면광고 메일이 같은 주에 겹치면, 회원이 받는 광고 메일은 **주 1통 상한**을 지키도록 전면광고를 월요일 메일 맨 위에 합치거나 하루 뒤로 미룬다(1단계 구현 때 확정).
- `noreply` 주소는 인증 메일과 같은 도메인을 쓰므로, 광고 메일 문제(스팸 신고)가 생기면 인증 메일에도 영향이 갈 수 있다. 그래서 스팸 신고율 자동 중단 규칙(4번)을 반드시 넣는다.

## 8. 위험과 대비
- 동의율이 낮아 도달 인원이 적을 수 있음 → 가입·응모·정보 글 하단에 동의 접점을 늘리고, 동의 혜택(응모권 1개 등, 단 동의를 강요하지 않는 선에서) 검토.
- 광고주가 "내 손님 이메일을 달라"고 요구 → 거절(개인정보·동의 범위 밖), 대신 결과 보고서 제공.
- 스팸 신고 증가 → 자동 중단 규칙과 주 1회 상한이 방어선.
- 인접 주 정의가 광고주 기대와 다를 수 있음 → 신청 화면에서 포함되는 주 목록을 미리 보여 주고 직접 빼거나 더할 수 있게 함.
