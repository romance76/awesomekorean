# 3D 추첨기 꾸미기 가이드 (Kay용)

## 1. 추첨 화면(게임) 고르기
1. 관리자 > **경품 추첨(Sweepstakes) 관리** 로 이동
2. 꾸밀 이벤트 카드의 **추첨 화면 꾸미기** 버튼 클릭 (당첨자 발표 후에는 수정 불가)
3. 두 가지 중 선택
   - **2D 룰렛 휠**: 기존 룰렛 (꾸미기 옵션 없음)
   - **3D 추첨기(공 뽑기)**: 공이 섞이다 당첨 번호가 나오는 3D 화면 (색·배경·로고 꾸밀 수 있음)
4. 이벤트를 새로 만들 때(이벤트 등록 > 경품 추첨 체크)에도 같은 선택지가 있어요. 색상 꾸미기는 등록 후 위 화면에서 합니다.
5. 오른쪽 **미리보기**에서 바로 확인하고 **저장**을 누르면 끝.

## 2. 색상·배경·로고·상품 이미지 바꾸기 (3D 선택 시)
- **추천 테마 버튼**: 네이비·골드 / 어썸코리안 핑크·오렌지 / 민트 스튜디오 / 크리스마스 / 심플 화이트. 누르면 한 번에 적용, 이후 색을 더 고칠 수 있어요.
- **색상**: 배경 위/아래, 포인트 색(글자·장식), 바닥, 유리 색. 색 칸을 눌러 고르거나 `#RRGGBB` 직접 입력.
- **공 색상**: 최대 8개까지 추가(+)/삭제(×).
- **이미지**: 상품 이미지 / 배경 이미지 / 로고 — 「이미지 선택」으로 올리고, 「제거」로 지울 수 있어요. 로고를 안 올리면 사이트 기본 로고가 나오고, 「화면에 로고 표시」 체크로 숨길 수 있어요.

### 권장 이미지 규격
| 종류 | 크기 | 형식 | 용량 |
|---|---|---|---|
| 상품 이미지 | 약 800x800 | png / jpg | 1MB 이하 |
| 배경 이미지 | 1920x1080 | jpg | 1.5MB 이하 |
| 로고 | 가로 약 512px, 배경 투명 | png | 500KB 이하 권장 |

배경 이미지는 글자·공이 잘 보이도록 너무 밝거나 복잡하지 않은 것이 좋아요.

## 3. 코드에서만 바꿀 수 있는 것 (개발자 작업)
- 추첨기 모양, 공 개수, 애니메이션 속도/시간 → `resources/js/components/LotteryStage3D.vue`
- 기본 색상(아무것도 안 고를 때의 색) → `resources/js/composables/useLotteryTheme.js`
- 새로운 추첨 게임 추가 → `AdminSweepstakes.vue` 의 `DRAW_STYLES` 배열에 한 줄 + 해당 화면 컴포넌트 + 백엔드 `draw_style` 허용값

## 4. 추첨은 어떻게 공정하게 이루어지나
- 당첨자는 **서버가 안전한 난수로 1회만** 뽑고, **감사 기록(audit)** 이 남아요. 되돌릴 수 없어요.
- 3D 화면은 **저장된 결과를 연출로 다시 보여 줄 뿐**이라, 몇 번을 다시 재생해도 **항상 같은 당첨자**가 나와요.
- 화면에는 닉네임만 표시해요.

## 5. 이벤트 진행 순서
1. 이벤트 등록에서 **경품 추첨(Sweepstakes)** 으로 생성 (경품명·가치·최소 연령·지역·공식 규정 URL·무구매 안내문)
2. 추첨 화면 꾸미기에서 3D 선택 + 테마 설정 + 미리보기 확인
3. 회원들이 **응모권(Entry)** 을 사용해 참가 (응모권은 구매 불가, 활동으로만 획득)
4. 마감 후 관리자 **당첨자 선정** 클릭 → 서버가 추첨, 3D 화면으로 결과 재생
5. 당첨자에게 디지털 기프트카드(예: 스타벅스)를 직접 발송하고 발송 내역 보관
