- **친구**: 상단 메뉴에서 빼고 MY(프로필 메뉴 · 휴대폰 전체 메뉴 맨 아래)로. 주소 `/friends` 는 그대로.

## 1단계 — 메뉴 트리 + 상단/휴대폰 메뉴 + 머리줄 (MONEY 는 자리만)

**저장 방식 (기존 것 안 깨기)**
- 지금 `site_settings.menu_config`(메뉴 한 줄 목록: 이름·경로·켜기/끄기·관리자 전용·로그인 필요)는 **그대로 둠**.
- 새로 `site_settings.menu_groups` 하나 추가: `[{key, label, label_en, icon, type: single|group|hub, hidden, items:[메뉴 key…]}]` (순서 = 배열 순서).
- **켜고 끄는 스위치** `menu_groups_enabled` — 처음엔 꺼 둔 채 배포 → Kay 가 관리자 화면에서 확인 후 켬. 문제 있으면 끄면 바로 예전 메뉴로 돌아감.
- 마이그레이션은 기본 묶음(위 표)을 `menu_groups` 에 **없을 때만** 넣음(다른 데이터 수정 없음).

**작게 나눠 배포 (각각 `ship.sh`)**
1. 서버: `GET/POST /api/admin/settings/menu-groups`(최고관리자 — `settings/*` 규칙 그대로, 감사 로그 자동), 검증(이름 1~30자·< > 금지, 메뉴는 한 묶음에만, 없는 메뉴 key 거부), 공개 설정 API 에 `menu_groups`·스위치 포함.
2. 관리자 › 사이트 설정 › 메뉴: **트리 화면** — 끌어서 순서·묶음 이동(휴대폰은 ▲▼ 버튼), 묶음 이름 바로 고치기, 종류 고르기(단독/묶음/허브), 숨김, "+ 묶음 추가", 오른쪽 미리보기, 저장·처음 상태로.
3. PC 상단: 묶음 메뉴 + 마우스 올리면 펼침 / 휴대폰 ☰: 묶음 제목 아래 메뉴 / MY 에 친구. 하단 탭은 지금처럼 메뉴별 별표(순서는 묶음 순서를 따름).
4. 공용 머리줄 부품 `PageHead.vue` 를 만들어 목록 페이지에 차례로 적용(한 번에 3~4 페이지씩): 게시판·Q&A·채팅·동호회 / 중고장터·공동구매 / 업소록·NEW / 뉴스·레시피·이벤트 / 숏츠·음악. 각 페이지의 위치·검색 칸은 오른쪽 자리로 옮기기만.
5. `/info`(서버가 그리는 정보 페이지)도 같은 머리줄·상단 메뉴(`InfoPublicController::headerMenus`).
6. 스위치 켜기 전·후 PC/휴대폰 화면을 모든 묶음에서 확인(가로 넘침 검사 포함).

## 2단계 — MONEY 허브 (따로 계획서 → Kay 확인 후)

- `/money` 허브 첫 화면(샘플 그대로 구조).
- **정보 공유 카페 11개**와 **머니 게시판**: 지금 커뮤니티 게시판(`boards`) 구조를 재사용하는 안(카페/머니게시판 구분 칸만 추가) — 가입 없이 보기·답글, 글쓰기는 로그인, 나중에 카페 운영자 지정.
- **머니 가이드**: 운영자가 쓰는 설명 페이지(게시판 아님) — 정보 페이지(`/info`)와 같은 방식 재사용 검토.
- 주식 카페에 지금 홈의 주식 시세 위젯 연결. 내돈내산 리뷰는 지금 게시판을 머니 게시판으로 위치만 이동.
- 금융·세무·보험 안내 문구("전문가 상담 대체 아님") 필수.

## Kay 결정 필요
1. 1단계를 위 순서대로 시작해도 되는지 (스위치 꺼 둔 채 배포 → 확인 후 켜기).
2. MONEY 정식 이름(관리자 화면에서 나중에 바꿔도 됨).
3. 2단계(MONEY)는 1단계가 끝난 뒤 따로 계획서를 먼저 보여 드리기 — 괜찮은지.
