# 사이트 점검 보고서 — 2026-10-14 (로그인 없이 보이는 화면 + 서버 코드)

## 이번 점검의 범위와 한계 (먼저 읽어 주세요)
- **한 것:** 로그인 없이 열리는 모든 화면(홈·커뮤니티·Q&A·구인구직·장터·부동산·업소록·정보·뉴스·레시피·이벤트·동호회·공동구매·MONEY·쇼핑·숏츠·음악·약관·소개·문의·로그인·가입)을 브라우저로 직접 열어 보고, 글 상세 화면, 휴대폰(375px) 화면, 공개 API에 비정상 입력을 넣어 본 결과, 그리고 글쓰기·수정·답글을 처리하는 서버 코드를 읽어 본 결과예요.
- **못 한 것:** 가입·로그인 후의 실제 동작(글쓰기, 답글, 마이페이지, 관리자 화면). 운영 사이트에서는 제가 계정을 만들거나 비밀번호를 입력해 로그인하는 것이 금지돼 있고, 시험 글을 올리면 공개 콘텐츠가 바뀌기 때문이에요. 이 부분은 서버 코드를 읽어서 허점을 찾았어요. 본인이 브라우저 창에서 직접 로그인해 주시면 같은 방식으로 이어서 점검할 수 있어요.

## B. 발견했지만 제가 임의로 바꾸지 않은 것 (결정·승인 필요)

### 높음
1. **메뉴에서 뺀 서비스 화면이 주소로 직접 열려요.** `/games`("카지노 대기실·포커" 게임 센터), `/elder`(안심서비스), `/poker7`(로그인 요구). 특히 **`/elder` 소개는 "보호자가 등록하면 시스템이 자동으로 전화를 걸어 확인합니다"라고 약속하는데, 이 서비스의 서버 작업이 꺼져 있어 실제 전화가 가지 않아요.** 안전 서비스라 오해의 소지가 커요. → 화면을 주소 이동(홈으로) 처리하거나 "준비 중" 안내로 바꾸는 것을 권해요.
2. **이용약관이 운영하지 않는 서비스를 약속해요.** 서비스 정의에 "게임, 숏츠, 음악듣기"가 있고, 제24조 "게임 및 가상재화에 관한 특칙"("미니게임… 도박에 해당하지 않습니다")이 있어요. 법적 문서라 임의로 고치지 않았어요. 한국식 용어("청약철회" 등)가 많은데 서비스 대상은 미국 한인이라 검토가 필요해요.
3. **수집·복사 콘텐츠가 많아요(저작권·애드센스 정책·신뢰 문제).**
   - 중고장터 #943: 다른 쇼핑몰 상품이 "판매중 $14.86"로 올라와 있어요(실제로는 여기서 살 수 없음).
   - Q&A #7848: 작성자 `ask_me_this`, 번역투 — 영어권 커뮤니티 글을 옮긴 것으로 보여요(지식인 4,400건 처리 방침과 같은 문제).
   - 뉴스 #40997: 뉴시스 기사 본문(기자 이름·문장 그대로)이 사이트 안에 실려 있어요. 원문 링크는 있지만, 뉴스 본문을 그대로 옮기는 것은 저작권·애드센스 "복사된 콘텐츠" 정책에 걸릴 수 있어요(제목·요약 + 원문 링크만 두는 방식을 권해요).
   - 구인 #296: 대기업 공고를 가져온 것으로 보이고 연락처가 로그인 없이 보여요.
   - 업소록: "한인 업소록"에 Kroger, Midtown Cleaners, Eurofed Automotive 등 **한인이 아닌 업체**가 섞여 있고, 업종이 `etc`·`medical`·`beauty`·`professional`처럼 영어 원문 그대로 보이는 곳이 있어요.
4. **더미 글이 공개돼 있어요.** 커뮤니티 #90 "요즘 이게 화제더라고요… 저도 경험해보니 정말 그런 것 같아요"는 똑같은 틀의 자동 생성 글이에요(더미 계정 정리 항목과 같은 문제).
5. **공동구매: 마감이 지난 글이 계속 "모집중"이에요.** "김치 공동구매 — 모집중, 마감 9월 24일"인데 오늘은 10월 14일이에요. 마감일은 **가입할 때만** 검사하고, 마감 뒤 상태를 바꾸거나 환불하는 자동 작업이 없어요(돈이 걸린 부분이라 자동 처리를 임의로 만들지 않았어요).

### 중간
6. **쓰기에 전용 횟수 제한이 없어요.** 글·구인·장터·업소·부동산 등록은 전체 한도(회원당 분당 400회)만 걸려 있어 도배가 가능해요. 권장: 글 등록 분당 5회·일 50회 정도의 전용 제한.
7. **검증이 없는 쓰기 함수가 더 있어요(A4에서 4곳만 고침).** 업소 정보·메뉴·사진 수정(`BusinessController::updateMyBusiness/updateMenu/uploadMyBusinessPhotos`), 이력서 수정(전화·이메일 등 개인정보 칸, `ResumeController::update`), 쇼핑 후기 등록·수정(`ShoppingController::storeReview/updateReview`, 이미지 업로드 포함), 구인 지원(`JobController::apply`), 친구 신청(`FriendController::sendRequest`), 행사 참석(`EventController::toggleAttend`), 주식 관심종목(`StockController::addWatch`). 일부는 소유자 확인이 코드에 보이지 않아 로그인 점검 때 확인이 필요해요.
8. **공개 화면의 구조 문제:** 큰 제목(h1)이 없는 화면(커뮤니티, Q&A, 업소록, 뉴스, 레시피, 정보 목록), 대체 글(alt) 없는 이미지(장터 21개, 업소록 20개, 뉴스·레시피 24개) — 검색 순위와 접근성에 불리해요.
9. **로그인 화면의 터치 영역이 너무 작아요(휴대폰).** "비밀번호를 잊으셨나요?"와 "회원가입"이 높이 16px, 상단 로그인·시작하기·EN과 해시태그는 25~32px. (권장 44px)
10. **가입 폼 입력칸에 `name`/`autocomplete`가 없어요** → 비밀번호 관리자·자동완성이 잘 안 돼요.

### 낮음
11. 부동산 이미지가 `http://`로 불려 와 브라우저가 자동으로 `https`로 올려 줘요(경고만 뜸). 외부 사이트 이미지를 그대로 쓰고 있어, 그쪽이 막으면 깨져요.
12. 동호회는 현재 1곳(엣시 셀러)뿐이라 화면이 비어 보여요.
13. 공개 사이트에 "광고 위치 확인하기"라는 광고주용 안내가 여러 화면에 반복돼요(의도된 것으로 보이지만 일반 이용자에게는 군더더기).

## C. 정상으로 확인한 것
- 휴대폰에서 가로 넘침 없음, 입력칸 글자 16px(iOS 확대 없음)
- 로그인이 필요한 화면(`/chat`, `/poker7` 등)은 로그인 화면으로 이동하고 돌아올 주소(`redirect`)를 안전하게 처리
- 개인 프로필 API는 로그인 없이 401
- 글 등록(`store`)은 길이·이미지·금칙어·HTML 제거까지 꼼꼼해요
- 이용자 글은 화면에서 이스케이프되어 출력(`v-html`은 관리자 가이드·정리된 팝업에만 사용)
- 검색 API는 따옴표·스크립트 문자열에도 오류 없이 응답
- 소개·개인정보처리방침은 미완성 문구 없이 채워져 있고, 개인정보처리방침에는 쿠키·CCPA·아동·광고·삭제 항목이 있어요

## D. 로그인 후에 점검해야 할 것 (본인이 로그인해 주시면 이어서 가능)
가입 → 이메일 인증 → 글쓰기(이미지 10장·20,000자 경계) → 수정 → 삭제 → 댓글·답글 → 좋아요 → 신고 → 쪽지 → 친구 → 프로필 수정(닉네임·소개·사진) → 마이페이지(포인트·결제·알림·회원탈퇴) → 장터(등록·끌올·홀드) → 구인(지원) → 관리자(회원·신고·광고·설정). 점검 중 만드는 시험 글은 "[점검 시험]"으로 표시하고 끝나면 지우겠어요.
